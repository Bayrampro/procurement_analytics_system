# Инструкция по настройке проекта

## Шаги для запуска проекта

### 1. Установка зависимостей

```bash
flutter pub get
```

### 2. Генерация кода базы данных (обязательно!)

Перед первым запуском необходимо сгенерировать код для работы с базой данных Drift:

```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

Эта команда создаст файл `lib/data/data_sources/database.g.dart`, который необходим для работы приложения.

### 3. Запуск приложения

После успешной генерации кода можно запустить приложение:

```bash
flutter run -d windows
```

## Решение проблем

### Ошибка: "Target of URI hasn't been generated"

Если вы видите ошибку о том, что файл `database.g.dart` не найден, выполните шаг 2 (генерация кода).

### Ошибки компиляции после изменений в database.dart

Если вы изменили структуру базы данных в `lib/data/data_sources/database.dart`, необходимо повторно запустить генерацию:

```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

## Импорт данных

1. Запустите приложение
2. Перейдите на экран "Импорт данных"
3. Нажмите "Выбрать файл" и выберите CSV файл
4. Нажмите "Импортировать"

Пример CSV файла находится в корне проекта: `procurements_source.csv`
