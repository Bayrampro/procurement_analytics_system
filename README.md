# Информационная система «Анализ торговых площадок в сфере закупок»

Информационная система для сбора, хранения, анализа и визуализации данных о закупках, размещённых на электронных торговых площадках.

## Технологии

- **Flutter** - фреймворк для разработки
- **Dart** - язык программирования
- **SQLite (Drift)** - база данных
- **fl_chart** - библиотека для графиков
- **file_picker** - выбор файлов для импорта

## Установка и запуск

### 1. Установка зависимостей

```bash
flutter pub get
```

### 2. Генерация кода для базы данных (Drift)

Перед первым запуском необходимо сгенерировать код для работы с базой данных:

```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

### 3. Запуск приложения

```bash
flutter run -d windows
```

## Функциональность

### Основные возможности:

1. **Импорт данных**
   - Загрузка данных из CSV-файлов
   - Проверка корректности данных
   - Сохранение в локальную базу данных SQLite

2. **Просмотр списка закупок**
   - Отображение списка закупок в виде карточек
   - Основные сведения: площадка, заказчик, предмет, стоимость, статус

3. **Фильтрация и поиск**
   - Фильтрация по торговой площадке
   - Фильтрация по категории
   - Фильтрация по статусу
   - Фильтрация по диапазону цен
   - Фильтрация по дате публикации
   - Поиск по названию, заказчику, площадке

4. **Аналитика**
   - Количество закупок по торговым площадкам
   - Общая сумма закупок
   - Распределение закупок по статусам
   - Динамика закупок по времени
   - Распределение закупок по категориям

5. **Визуализация данных**
   - Столбчатые диаграммы
   - Линейные графики
   - Круговые диаграммы

6. **Детальный просмотр закупки**
   - Полная информация о выбранной закупке

## Формат CSV файла

CSV файл должен содержать следующие колонки:
- `id` - идентификатор
- `platform` - торговая площадка
- `customer` - заказчик
- `title` - предмет закупки
- `category` - категория
- `price` - стоимость
- `published_date` - дата публикации (формат: YYYY-MM-DD)
- `status` - статус
- `region` - регион

Пример:
```csv
id,platform,customer,title,category,price,published_date,status,region
1,ЕИС,ГБУЗ ГКБ №1,Поставка медицинских перчаток,Медицина,1200000,2024-01-10,Завершена,Москва
```
